AgentID Book

Agent IDs are Binance Wallet names ending in .ai. Resolution lives off-chain, so no contract can read them. This book puts them on BNB Chain: a holder signs once, anyone pays the gas, and every dApp can gate on the name.

The contract verifies an EIP-712 signature from the address your Agent ID resolves to, so nobody can bind a name they do not own. One name per address, one address per name. Gas is paid by the relayer.
